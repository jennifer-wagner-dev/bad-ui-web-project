# 🎨 Bad UI – Pokémon Edition

An intentionally frustrating web application built to explore bad user experience and unusual interface patterns.

The project was developed as part of my software development training. The goal was not to create a good interface, but to deliberately break common usability principles while still keeping the application functional.

## 🚀 Features

- Multiple interactive pages
- Intentionally confusing navigation and UI elements
- Custom cursor effects
- Random visual and background effects
- Pokémon-themed design
- Interactive forms and user actions
- Dynamic content and JavaScript-based behaviour
- API integration

## 🛠 Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- REST APIs

## 💡 Concepts Used

- DOM manipulation
- Event handling
- Functions and modular JavaScript
- Asynchronous API requests
- Dynamic content
- Form handling
- CSS layouts and animations
- Separation of JavaScript functionality across multiple files

## 🧠 What I Learned

This project gave me the opportunity to experiment with JavaScript and DOM manipulation in a more creative way.

Because the goal was to intentionally create a bad user experience, I had to think about what normally makes an interface intuitive and then deliberately do the opposite.

The project also helped me practise structuring a larger frontend project across multiple HTML, CSS and JavaScript files and combining different interactive effects without breaking the overall functionality.

## ▶️ Running the Project

Clone the repository:

`git clone https://github.com/jennifer-wagner-dev/bad-ui-web-project.git`

Then open `html/index.html` in your browser.

## ⚠️ About the Project

This project intentionally demonstrates poor usability patterns for educational purposes. The confusing interactions and unusual design choices are features, not bugs. 😄
